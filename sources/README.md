# sources/ — 一次情報と再現用スクリプト

## 一次情報（このリポジトリには含めていません）

**新宿区 おくやみガイドブック（令和8年4月発行・48ページ）**
https://www.city.shinjuku.lg.jp/content/000398612.pdf

`data/procedures.json` の期限・受付窓口（課／係）・必要書類は、この冊子の
「区役所での手続きチェックリスト」（P7-10）を逐条で構造化したものです。

PDF 本体は同梱していません。配布ページにライセンス表記がなく、
「公開されているPDF」＝「オープンデータ」ではないためです（README §6.5）。
再現する場合は上記 URL から取得してください。

## スクリプト

データ構築・検証に使ったもの。実行順に意味があるわけではなく、
その時々の調査・変換の記録です。

| ファイル | 用途 |
|---|---|
| `ck.py` / `wards.py` / `chk2.py` | 東京都オープンデータカタログ（CKAN API）の探索・23区の公共施設データ比較 |
| `build_moving.py` / `build_life.py` | 引っ越し・就職・退職・結婚・出産シナリオの手続を生成 |
| `build_conditions.py` | 質問（conditions.json）をシナリオ別タグ構造へ再構成 |
| `fix_exprs.py` / `fix_variants.py` | 条件式の型不整合の修正、シナリオ別の問い方の追加 |
| `*_ward_event_matrix*.mjs` | 23区ソースマトリクスの適用・検証・レポート生成 |

**注意:** CKAN API を Git Bash の curl から叩くと日本語クエリが文字化けします
（フレーズ検索が0件になる）。Python の urllib を使ってください。
User-Agent はブラウザUAが必要です（Webページは403、APIは通る）。
